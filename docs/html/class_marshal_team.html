Detailed Description

GoF role: ConcreteComponent (Composite) and ConcreteObserver (Observer), with an extra ability of its own, it can originate a HAZARD_ALERT Notice via createHazardNotice() rather than only ever reacting to notices issued by EventControl.

Handles event notifications affecting the marshal team.

Different notice types trigger different behaviors:

  • WEATHER_ALERT: Redirects runners away from danger
  • HAZARD_ALERT: Responds to hazards with appropriate actions
  • EVACUATE: Assists in evacuation procedures
  • ROUTE_CHANGE: Implements route changes
