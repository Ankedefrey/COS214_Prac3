GoF Component role for the Composite pattern. 

\doxylink{class_event_component}{Event\+Component} is the common interface for every part of the event tree, whether it\textquotesingle{}s a single operational unit or a group containing further components. Code that just wants to open/\+close/\+report on/\+query part of the event can hold an Event\+Component\texorpdfstring{$\ast$}{*} without knowing which concrete kind it is.

\doxylink{class_event_component}{Event\+Component} also implements \doxylink{class_observer}{Observer}, so every component in the tree is capable of receiving notices, this is a separate collaboration from Composite, and is why some subclasses (\doxylink{class_event_group}{Event\+Group}) additionally implement \doxylink{class_subject}{Subject}: a component can both receive notices from above and forward them to interested parties below.

Called by a \doxylink{class_subject}{Subject} to deliver a \doxylink{class_notice}{Notice}. 

This design uses the "{}push"{} style of \doxylink{class_observer}{Observer}: the \doxylink{class_subject}{Subject} passes the full \doxylink{class_notice}{Notice} (type, message and severity) directly into this call, so the \doxylink{class_observer}{Observer} never needs to query the \doxylink{class_subject}{Subject} for state.
