\doxysubsection{Detailed Description}
GoF \doxylink{class_subject}{Subject} role: something that can be observed A \doxylink{class_subject}{Subject} keeps a list of registered \doxylink{class_observer}{Observer} pointers and notifies them when something changes. The \doxylink{class_subject}{Subject} never owns the Observers it stores, every pointer here is non-\/owning. An \doxylink{class_observer}{Observer} must be detached (or must outlive the \doxylink{class_subject}{Subject}) before it is destroyed, otherwise the \doxylink{class_subject}{Subject} is left holding a dangling pointer.
