The message passed from a \doxylink{class_subject}{Subject} to its Observers. 

This is the payload used by this project\textquotesingle{}s "{}push"{} \doxylink{class_observer}{Observer} implementation: it carries everything an \doxylink{class_observer}{Observer} needs (what happened, a human-\/readable description, and how serious it is) so the \doxylink{class_observer}{Observer} never needs to call back into the \doxylink{class_subject}{Subject} to ask for more information.
