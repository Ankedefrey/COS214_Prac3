\doxysubsection{Detailed Description}
GoF \doxylink{class_observer}{Observer} role: anything that wants to react to a \doxylink{class_notice}{Notice}. 

Any class that needs to be told about events happening elsewhere in the Event\+Flow tree implements this interface and registers itself with a \doxylink{class_subject}{Subject} via \doxylink{class_subject_ab6d78de2ea944a23dc5a66a4fe580db2}{Subject::\+attach()}. A single object may be attached to more than one \doxylink{class_subject}{Subject} at a time.

Called by a \doxylink{class_subject}{Subject} to deliver a \doxylink{class_notice}{Notice}.
